This project implements a Distributed Retrieval-Augmented Generation (RAG) System that enables scalable semantic search over large text corpora. Using PySpark for distributed embedding generation, SentenceTransformers for text embeddings, and FAISS for sharded vector indexing, the system efficiently processes large datasets into searchable vector representations. User queries are executed in parallel across FAISS index shards, with the top results merged to provide low-latency, high-quality retrieval for downstream RAG applications. The pipeline was evaluated on both a single node and a GCP cluster, demonstrating improved scalability, throughput, and retrieval performance for large-scale semantic search.
